# 기운찬 홈페이지 로컬 초안

기획 문서와 시나리오 v2를 바탕으로 만든 정적 멀티페이지 홈페이지입니다. 31개 URL을 제공하며 서버 렌더링 대신 빌드 시 실제 HTML을 생성합니다. 현재는 공개 검수 전 로컬 초안이며 외부 배포하지 않았습니다.

## 실행

Node.js 20 이상에서 의존성 설치 없이 실행합니다.

```sh
npm run build
npm run dev
npm run check
```

미리보기 주소는 http://127.0.0.1:4173 입니다. 서버는 dist만 제공하며 content와 review는 외부에 제공하지 않습니다.

## 파일 역할

- scripts/build.mjs: 페이지 생성과 레이아웃
- scripts/visuals.mjs: 페이지별 이미지 구성·인포그래픽·시각적 콘텐츠 렌더러
- dist/style.css, dist/visual.css, dist/app.js: 직접 관리하는 공통 스타일·동작 소스
- dist/assets: 원본을 보존하며 최적화한 웹 이미지
- content/scenario.json: 원고 및 내부 메모가 있는 개발용 데이터. 공개 자산에 복사하지 않습니다.
- review: 원고 대응표, 이미지 대응표, 검수 결과와 내부 확인 사항
- scripts/prepare.py, assets.py: 최초 자료 준비용 도구. Python·Pillow가 필요하며 경로는 이 작업 환경 기준입니다. 이미 생성된 JSON·이미지가 있으면 재실행할 필요가 없습니다.

## 현재 동작과 미완료

페이지 직접 접속, 반응형 메뉴, FAQ, 인사이트 검색·분류, 문의 유형·소재·제품 자동 선택, 문의 입력 검사를 제공합니다. 문의는 서버 전송·저장하지 않으며 화면에 이를 표시합니다. 실제 구매 URL·개인정보 방침·뉴스 원문·제품 표시정보·연구 공개 범위 확인은 남아 있습니다.

모든 페이지는 noindex이며 서버는 로컬 주소에만 바인딩합니다. noindex는 비공개 보호 수단이 아니므로 현재 dist 전체를 외부에 공개하지 않습니다. 공개 전 제품·연구 초안을 검수하고 내부·미확정 콘텐츠를 공개 빌드에서 제외하는 절차가 필요합니다. canonical·공개 sitemap·분석·문의 연동은 배포 단계에서 확정합니다.

GitHub 저장 및 Vercel 배포는 아직 수행하지 않았습니다. 공개할 때 정적 출력 폴더는 dist입니다.
