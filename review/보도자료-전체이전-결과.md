# 보도자료 이전 및 연구 발자취 이미지 교체 결과

## 이전 규모
- 공개 보도자료 16건 모두 이전
- 상세페이지 16개: /insights/press/[원본 slug]/
- 고유 대표 이미지 12개: 원본 바이트 유지, /assets/press/에 보관
- 원본을 찾지 못한 게시물: 없음
- 기존 데이터의 카테고리와 모든 원본 필드 보존, 화면 카테고리 미노출

## 원본 대조
로컬 giunchan-site-github/lib/content-data.ts 및 Git 이력, 기존 배포 /newsroom의 전체 서버 전달 데이터 16개 slug를 대조했습니다. 기존 migration inventory의 15건은 이후 추가된 2026 인체적용시험 글을 포함하지 않는 과거 집계입니다. 실제 공개 데이터는 16건입니다.
홈페이지 날짜는 원본 publishedAt, 수정일은 updatedAt을 유지했습니다. 원문 발표일 별도 필드는 원본에 없으므로 임의로 만들지 않았으며, 출처 라벨에 있는 원문 날짜를 그대로 표시했습니다. publishedAt을 외부 기사 날짜에서 새로 계산하지 않았습니다. 원본 본문과 과거 ‘현재 상태’ 설명을 수정하지 않고 요청한 하단 안내문을 덧붙였습니다.

## 화면 및 연결
- 기존 연구소개 카드 HTML, 히어로, 헤더, 푸터 그대로 유지
- 연구소개/보도자료 두 탭. 기존 전체 필터·검색 UI 제거, 추가 하위 분류 없음
- 보도자료 전체 16건 한 번에 표시, publishedAt 내림차순·동일 날짜 원본 순서
- PC 1440px 3열, 태블릿 820px 2열, 모바일 360px 1열
- PC 16개 카드 모두 폭 384px/높이 597.4375px 동일, 마지막 행 폭 유지
- 동일 16:9 이미지 틀에 contain 적용: 원본 왜곡·중요 부분 잘림 방지
- 상세 본문 4개 섹션 및 출처 링크·원래 제목·기자·관련 기관·연구단계 유지
- 카테고리 배지 미표시, 상세페이지 title/description/NewsArticle/게시·수정일 및 사이트맵 포함
- 기존 사이트의 noindex/robots 정책은 그대로 유지됨(검색엔진 노출 정책은 별도 변경하지 않음)

## 기존 주소
현재 도메인의 /newsroom/[slug]/ 16개에 새 상세페이지로 자동 이동하는 호환 페이지를 추가했습니다(HTML meta refresh; HTTP 301은 아님). 별도 뉴스룸 목록은 만들지 않았습니다. 기존 vercel.app 도메인을 방문하는 사용자를 새 사이트로 자동 이동시키려면 원본 배포의 리다이렉트 설정이 별도로 필요합니다. 원본 사이트는 변경·삭제하지 않았습니다.

## 연구 근거 인포그래픽 교체
추가 요청에 따라 12건 영역 아래의 흐름·연도별 HTML 카드부터 ‘연구에서 제품화까지’ 앞 구간을 첨부 giunchan-rnd-timeline-content-only.png 원본 한 장으로 교체했습니다. 상단 제목·도입·12건 및 하단 요약 유지. 이미지 클릭 시 원본 크기로 열립니다. 원본 내용/특허 수 등은 이미지 그대로이며 앞선 HTML 검증 결과로 재작성하지 않았습니다.

## 검증
31개 기존 경로+16개 상세+16개 호환 경로=63개 경로 검사 통과. 모든 원본 제목·본문·날짜·외부 링크 및 이미지 해시 대조 통과. PC/태블릿/모바일 가로 넘침 없음. 상세페이지 클릭·목록 복귀·탭 키보드 이동 확인. 검증 브라우저 콘솔 오류 0. JavaScript 프로젝트로 별도 TypeScript 검사 구성 없음.
