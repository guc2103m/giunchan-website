# 디자인 보완 결과

기존 원고 중심 상세 페이지를 페이지 성격별 시각적 구성으로 보완했습니다.

| 영역 | 변경 |
|---|---|
| 홈·GMK 기술 | 접종·복합배양·GMK·원료 및 제품의 연결을 아이콘과 단계 도식으로 표현 |
| 회사소개 | 기업 이야기 이미지 분할, 핵심 분야 카드, 대표 메시지 강조, 비전·실행 카드, 연구 이미지 모음, 기업 정보 그리드 |
| 연혁·실천 | 세로 연혁 타임라인, 자연·배양 이미지와 원고의 교차 배치 |
| R&D | 연구 분야 사진 카드, 인체적용시험과 인정 절차 단계 구분, 연구자료 바로가기 |
| 연구 근거·특허 | 논문 4편의 연도·제목·원문을 카드로 구성, 안전성·시험 지표·특허 건수 시각화 |
| 원료·제품화 | 형태별 원료 카드, 검토 항목 체크리스트, 6단계 제품화 절차, 회사·제조 파트너 역할 도식 |
| 도두On | 자연 생장 흐름, 숲 이미지와 브랜드 메시지, 연구에서 일상까지 연결도, 브랜드 의미, 제품 카탈로그 |
| IR | 기술·지식재산·연구·사업화 기반, 수익모델, 성장 과제 카드 |
| 제품·문의 | 제품 정보 띠, 사용법·제품 사진 분할, 문의 이미지와 입력 영역 정리 |

제공 이미지 6종을 추가 최적화해 배양·현미경·연구·소재 이미지를 활용했습니다. 실제 기운찬 시설임을 확인하지 않은 이미지는 실제 현장이라고 표기하지 않았습니다. 도식은 텍스트·HTML·SVG로 구성해 모바일에서도 읽을 수 있습니다.

원고 대조에서 성과 수치의 카드 분리와 논문명 접두어 생략을 제외한 검사 대상 문단·표 셀의 누락은 발견되지 않았습니다. 검사 범위는 content-audit.py에 명시되어 있으며, 기존부터 보류한 P09 표시정보·CT 문의 연동·N01 UI 문구·편집 지시는 전수 본문 비교 대상에서 제외했습니다. 논문 제목과 연구 수치 자체는 유지했습니다.

31개 페이지를 1440·390·360px에서 검사했고 768px 태블릿 폭을 추가 확인했습니다. 주요 도식과 원료·연구·브랜드 화면을 캡처로 검수했습니다. 구체적인 결과는 browser-check.json 및 design-review.json을 확인합니다.

공개 배포와 실제 문의·구매 연동 상태는 변경하지 않았습니다.
