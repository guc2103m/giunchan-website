# 공개 전 확인과 남은 구현

## 자료 확인

- 제품 이미지 1번은 선물세트이며 2–8번은 기운차 진액·이뮨MK·버섯마시면 기운차·버섯한스푼·똑똑젤리·마시면 기운차·기운찬 本에 잠정 대응했습니다. 숫자만으로 매칭하지 않고 이미지에서 확인했습니다. 현행 SKU·라벨 최종 검수는 필요합니다.
- 코그니칸 제품 사진은 확인되지 않았습니다. 다른 제품 사진을 대신 쓰지 않고 텍스트로 표시했습니다.
- 버섯마시면 기운차 원고는 1g×15개, 제공 이미지에는 30g·15 Tea Bags로 보이는 표기가 있습니다. 원본 포장으로 확인해야 합니다.
- 똑똑젤리 용량, 버섯한스푼 SKU, 기운찬 本 표시사항, 코그니칸 판매 상태, 모든 제품의 현행 전성분·주의사항·제조원 등은 공개 전 확인합니다.
- 실제 제품·세트·스토어 URL 미확정으로 구매 CTA 대신 제품 문의 경로를 제공합니다. P09의 구매 버튼 FAQ는 구매 링크 확보 후 적용합니다.
- 연구 및 생산 이미지의 실제 회사 촬영 여부는 확인되지 않았습니다. 실제 기운찬 연구소·공장이라는 캡션은 넣지 않았습니다. 대표 사진·실제 쌀보리 사진·인증 자료가 필요합니다.
- 연구 결과·특허 상세·인정 절차 현행 상태·공개 출처와 대표 메시지는 담당자 검수 전입니다. 로컬 초안에만 배치했습니다.
- N04 실제 기사 원문·발행일 자료가 없어 뉴스 상세 실데이터는 생성하지 않았습니다. 보도자료 탭은 결과 없음 상태를 제공합니다.

## 기능과 공개

- 문의 전송·저장·동의문은 미연동입니다. 현재 폼은 입력 확인만 하고 전송하지 않습니다. 전화·메일 링크를 제공합니다.
- 개인정보처리방침은 준비 안내만 있습니다. 실제 정책을 임의 작성하지 않았습니다.
- 제품별 P09 표시정보 상세값이 미확정입니다. 로컬 화면에 항목과 문의 안내만 배치했으므로 제품 상세는 공개 준비 완료가 아닙니다.
- 영문·회원·결제·CMS는 범위 밖입니다.
- 기존 사이트 URL 이관, 대표 도메인, canonical·sitemap·공개 구조화 데이터, 분석 도구, 실제 뉴스 템플릿과 추가 원고 완전 대조는 후속입니다.
- 사이트 31개는 첫 구현 초안입니다. 사용자 디자인 검수 및 세부 원고·링크 검수 이후 GitHub 저장·Vercel 배포를 진행합니다.
