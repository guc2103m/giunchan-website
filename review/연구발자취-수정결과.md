- 2016–2017: 혈관형성 및 대사 관련 연구 / 세포·동물시험 확장 / 제품화
- 2018: 간 기능 관련 연구 / 간 조직 관련 세포·동물시험 / 후속 성과 2021년 특허 획득(2021.05.07)
- 2019: 안전성 연구 / 복귀돌연변이시험·소핵시험·염색체이상시험·단회투여독성시험·28일 및 90일 반복투여독성시험
- 2020–2025: 인지기능 관련 연구 / 알츠하이머 관련 병리 연구·세포 및 동물시험·학술논문 / 2023년 특허 획득(2023.09.01)
- 위 장기 연구 안의 2021 병행 연구: 폐 관련 세포·동물 연구 / 제품화
- 2024–2026: GMK® 추출물 인체적용시험 / 총 175명·16주·무작위배정 대조시험·김천의료원·고려대학교 구로병원 / 인체적용시험 완료

정부 중소기업 R&D 지원사업 12건 성공적 완료, 연구 흐름 요약 및 ‘연구에서 제품화까지’ 하단 메시지를 추가했습니다.

## 자료 대조 및 다르게 처리한 부분
- 간 관련 특허 10-2251825의 프로젝트 내 특허증 등록일은 2021.05.07입니다. 2018년 취득으로 표시하지 않고 해당 연구의 후속 성과로 명시했습니다.
- 인지기능 장기 연구의 특허 표시는 프로젝트 내 10-2575704 특허증의 2023.09.01 등록일에 근거합니다. 건수는 표시하지 않았습니다.
- 2016–2017 대사 분야 및 2021 폐 연구의 특허 취득 연도를 특정하는 일치 증빙은 확인하지 못해 해당 카드에 특허 취득 시점을 표시하지 않았습니다.
- 기운찬본: 현재 프로젝트 제품 데이터에서 동일 공식 명칭과 출시 시점을 확인하지 못했습니다. 제품명은 생략하고 제공 연혁에 근거한 ‘제품화’ 성과를 표시했습니다.
- 기운찬 이뮨M: 현재 데이터에는 기운찬 이뮨MK/기운찬이뮨MK로 표기되어 있습니다. 같은 제품이라고 임의 판단하지 않았으며 제품명은 생략하고 ‘제품화’를 표시했습니다.
- 2015 첨부 이미지의 연구 대상(위암·폐암·신장암·혈액암)과 요청문의 목록(간암·위암·폐암·신장암)이 다릅니다. 구체적인 최신 요청문 목록을 적용했습니다.
- 2019 안전성 연구 연도·독성/유전독성 범주는 기존 scenario RE03/CH02와 일치합니다. 개별 시험명 6개는 첨부 이미지와 요청문을 대조했습니다. 시험 원본 보고서는 별도 확인하지 못했습니다.
- 학술논문 발표 시점 2021/2023/2025는 기존 RE02와 대조했습니다. 타임라인에 새 논문 제목/DOI를 추가하지 않았으며 기존 2026 논문도 그대로 유지했습니다.
- 175명·16주·두 시험기관은 이번 요청문에서 공개를 명시한 정보를 사용했습니다. 기존 인체적용시험 섹션은 수정하지 않았습니다.
- 정부 R&D 12건은 이번 사용자 제공 문구가 근거입니다. 세부 과제 목록이나 완료 증빙은 프로젝트에서 확인하지 못했고 새 과제명을 만들지 않았습니다.
- 연구 연도 범위 및 제품화 표시는 첨부 연혁과 요청문에 근거합니다. 연구기관·공동연구자 이름은 요청한 시험기관 외 추가하지 않았습니다.

## 아이콘과 접근성
기존 SVG 라인 아이콘 culture, flask, search, shield, network, partners, document, box, check를 사용했습니다. 통이미지나 장기 사진을 추가하지 않았습니다. h2/h3, 실제 순서·항목 목록, aria-hidden 장식 아이콘을 사용하고 텍스트로 성과를 구분했습니다. 애니메이션이 없어 reduced-motion에서도 동일하게 읽을 수 있습니다.

## 검증
- PC 1440px: 중앙 세로축, 카드 좌우 교차, 연도 순서 확인
- 태블릿 820px: 왼쪽 축·한 열 전환, 카드 넘침 없음
- 모바일 360px: 왼쪽 축·한 열, 병행 연구 포함 가로 스크롤/카드 넘침 없음
- Pretendard Variable 확인, 본문 16px, 주요 라벨 14px
- 바로 다음 섹션이 RE02(전임상·학술 연구)임을 DOM으로 확인
- 새 섹션과 CSS 링크를 제거하면 기존 연구 근거 HTML과 완전히 동일
- 다른 30개 페이지 및 기존 모든 자산 해시 동일
- 31페이지 빌드 및 프로젝트 check 성공, JS 구문 검사 성공
- JavaScript 프로젝트로 별도 TypeScript 검사 구성 없음
