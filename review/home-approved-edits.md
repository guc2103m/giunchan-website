# 메인 페이지 사용자 수정 반영

- 적용 범위는 메인 URL `/`입니다.
- 화면에 보이는 GMK의 등록상표 기호를 작은 sup 요소로 표시합니다. 페이지 메타데이터와 이미지 대체 설명은 일반 문자 표기를 유지합니다.
- 메인 본문과 인포그래픽의 ‘함께 접종’을 ‘동시 접종’으로 바꿉니다. 사용자 명시 수정으로 기존 시나리오와의 차이를 허용합니다.
- H03 이미지에 새로 제공된 버섯·복합버섯균사체 이미지를 적용합니다. 원본은 content/gmk-material-original.png, 웹용은 dist/assets/gmk-material.webp입니다. 가로·세로 비율을 보존하며 잘리지 않게 contain으로 배치합니다.
- 다른 페이지의 이미지·문구는 이번 메인 수정 범위에서 변경하지 않습니다.
