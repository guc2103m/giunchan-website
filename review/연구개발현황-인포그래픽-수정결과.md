# 연구개발현황 인포그래픽 수정 결과

## 변경 범위
/rnd/의 R03 영역만 변경했습니다. 제목은 ‘현재 기운찬 중점 연구현황’, 라벨은 CURRENT R&D FOCUS로 변경했습니다. 첨부 이미지는 삽입하지 않았으며 HTML, CSS, 기존 SVG 라인 아이콘을 사용했습니다. 기존 ‘인체적용시험 요약’ 링크를 유지했습니다.

## 최종 단계 문구
1. STAGE 01 / COMPLETED / In Vitro / 세포시험 / CELL-BASED STUDY
   - ROS 활성산소 억제
   - Aβ 응집 차단
   - 신경세포 생존 증가
2. STAGE 02 / COMPLETED / In Vivo / 동물시험 / ANIMAL STUDY
   - Y-maze 공간기억 증가
   - GFAP/Iba-1 억제
   - 타우 독성 완화
3. STAGE 03 / COMPLETED / Human / 인체적용시험 / HUMAN STUDY
   - 55세~85세 MCI(경도인지장애)를 호소하는 성인 남녀
   - 고대구로병원, 김천의료원
   - 16주 무작위배정 대조 실험
   - 인지기능관련 지표 평가
4. STAGE 04 / IN PROGRESS / MFDS Recognition Process / 개별인정형 원료 인정 절차 / REGULATORY PROCESS
   - 현재 진행 중
   - 식약처 ‘개별인정형 원료 인정’을 위한 절차를 수행하고 있습니다.
   - 인체적용시험 완료
   - 관련 연구자료 정리
   - 인정 절차 진행

설명: 기운찬은 세포시험과 동물시험에서 확인한 연구 결과를 인체적용시험으로 확장했으며, 현재 식약처 개별인정형 원료 인정을 위한 절차를 수행하고 있습니다.

하단 RESEARCH CONTINUITY: 세포시험과 동물시험에서 인체적용시험으로 연구를 확장했으며, 현재 식약처 개별인정형 원료 인정을 위한 절차를 이어가고 있습니다.

## 수정 파일
- scripts/research-focus.mjs: 섹션 전용 렌더러 추가
- dist/research-focus.css: 섹션 전용 반응형 스타일 추가
- scripts/build.mjs: /rnd/의 R03에만 렌더러 및 스타일 적용
- dist/rnd/index.html: 생성 결과

## 아이콘
기존 visuals.mjs의 culture(배양 접시), flask(실험 플라스크), partners(참여·협력), document(문서), check(완료), clock(진행), network(연속성)를 사용했습니다. 연결 화살표는 같은 선 스타일 SVG입니다. 새 라이브러리를 설치하지 않았습니다.

## 검증
- PC 1440px: 4열, 동일 높이 541.5px, 가로 화살표
- 태블릿 820px: 2×2, 동일 높이 517.5px, 단계 번호와 연결 방향 표시
- 모바일 360px: 1열, 동일 높이 511.5px, 아래 방향 화살표
- 세 화면 모두 가로 스크롤 및 상태 라벨 넘침 없음
- Pretendard Variable 유지. 본문 16px 이상, 상태 라벨 14px
- h2/h3, ol/ul, aria-current=step 사용. 장식 SVG aria-hidden
- 강조 카드 흰색 글자/딥그린 배경 대비 12.14:1
- 애니메이션 없음
- 다른 30개 HTML과 기존 자산 해시 동일. R03와 해당 CSS 링크를 제외한 /rnd/ HTML 동일
- 31페이지 빌드 및 프로젝트 검사 통과, JS 구문 검사 통과
- JavaScript 프로젝트이며 별도 TypeScript 검사 구성 없음

## 연구 문구·수치
연령·대상자 설명·시험기관·16주 및 연구 항목은 사용자의 최종 수정 요청 그대로 반영했습니다. 새로운 수치·시험 결과를 추가하지 않았습니다. 원문 논문이나 인정 절차의 실제 진행 상태를 별도로 재검증한 작업은 아닙니다. ‘심사 중’, ‘인정 완료’, ‘승인 완료’ 표기는 넣지 않았습니다.
