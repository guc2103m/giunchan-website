## 구현

- 실제 HTML을 제공하는 31개 고정 URL 및 404 화면.

- 홈 H01–H09, 회사·연구·사업·브랜드·IR·제품의 시나리오 기반 본문 배치.
- 원료 3종·제품 8종 상세 경로, 인사이트 원고 2개와 검색·분류.
- 문의 유형과 관심 소재·제품 자동 선택, 필수 입력 검사. 실제 전송·저장 없음.
- 원고 ID 94개 대응 기록. E01–E07은 제작 규칙 검토이며 N04는 기사 자료 대기. P09·CT04는 부분 적용 상태를 별도 기록.

## 확인

- 정적 검사: 31개 페이지의 내부 링크·앵커·자산 존재, h1 1개, 주요 내부 메모 미노출 확인.
- 브라우저 검사: 1440·390·360px에서 31개 페이지 총 93회 검사. HTTP 상태, 가로 넘침, 이미지 로드, h1 수, 스크립트 오류 확인.
- 기능 검사: 모바일 메뉴·Escape, 원료 사전 선택, 소비자 회사명 선택 입력, 필수값 검사, 접수 성공으로 오인하지 않는 확인 메시지, 검색·분류·새로고침·뒤로가기·404.
- 화면 캡처: 대표 7개 페이지, 문의·제품·연구 상세의 PC·모바일 캡처 저장. 주요 첫 화면을 시각 검수.
- 브라우저 검수는 agent-browser 실행 파일이 없어 제공된 Playwright와 Edge로 수행.

이는 전체 글자·모든 상호작용·모든 화면 크기에 대한 완전 검증이나 공개 승인을 뜻하지 않습니다. 768px·200% 확대·색 대비의 정량 검수, 원고 전수 문자 대조와 사용자 화면 검수는 남아 있습니다.
